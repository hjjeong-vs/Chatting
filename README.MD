# OurNotion Project

## 개요
 * Notion을 업무에서 사용해보니 별도의 채팅 기능을 제공하지 않아 불편한 점이 많다.
 * 기존의 노션의 강점을 최대한 유지하며 채팅 기능을 별도의 exe와 같은 설치 파일 없이 제공한다.

## 구성

* 구성은 채팅 서버만 NodeJs 서버로 구성하고 이외 다른 서비스들은 Spring 부트로 제공한다.
* Nodejs와 Spring boot간의 통신은 보안 단계가 낮은 Http 프로토콜을 사용하며 웹 소켓을 이용하여 중요 정보 및 저장 시 Spring boot에서 처리 한다.
* 로그인은 네이버 API를 이용하여 별도의 회원가입을 간편화 하여 사용자에게 회원 가입시 낮은 장벽을 요구한다.
* 별도의 회원가입을 원할 경우 간단한 ID,PWD를 통한 가입도 진행 할 수 있다.
* 캘린더 기능을 제공하여 사용자의 업무를 효과적으로 관리 할 수 있으며 같은 팀원 혹은 협업자들에게 자신의 일정을 공유 할 수 있다.
  * 만일 공유를 원하지 않는다면 공유자를 조절 할 수 있다.
  * 월,주,일 단위로 볼 수 있어야 한다.
  * 해당 이벤트를 클릭 시 상세보기가 가능하여야 한다.
* 업무를 하다보면 급히 메모를 해야 할 경우 및 자신의 기록하고 싶은 것을 기록 할수 있어야 한다.
  * 메모는 반드시 텍스트로 진행하여야 하며 글꼴이나 글자 크기는 사용자가 원하는 것을 입력 할 수 있다.
  * 추후 이미지 및 gif 같은 파일을 첨부 할 수 있는지 여부는 정하겠다.
* 업무를 진행하다보면 개인적 혹은 팀원의 돈을 관리를 해야만한다.
  * 가계부를 간단하게 작성할 수 있으며 이때 가계부는 사용자가 다양하게 컬럼을 추가 하는것이 아니다
  * 사전에 미리 컬럼수를 정해 두었으며 추후 컬럼수를 커스텀으로 자유롭게 늘릴 여부를 정한다.
